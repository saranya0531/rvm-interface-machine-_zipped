The Reverse Vending Machine (RVM) is an automated recycling system designed to collect used plastic bottles and reward users for responsible waste disposal.

Unlike traditional vending machines, an RVM accepts recyclable items and provides incentives such as reward points, coupons, or digital credits.

This project integrates IoT, Embedded Systems, and Software Programming to promote sustainable waste management.

🎯 Objectives

Encourage recycling through reward-based system

Automate plastic bottle collection

Identify and validate recyclable materials

Maintain real-time data logging of collected items

🚀 Key Features

♻️ Accepts plastic bottles

🧠 Automatic object detection & validation

⚖️ Weight-based verification

🎁 Reward generation system

📊 Real-time data tracking

🔒 Secure user authentication (optional feature)

🛠️ Tech Stack

Hardware Components:

Microcontroller (Arduino / Raspberry Pi)

Ultrasonic Sensor

IR Sensor

Load Cell (Weight Sensor)

Servo Motor

LCD Display

Software & Tools:

Python

OpenCV (for bottle detection, if image-based validation used)

Embedded C (for microcontroller programming)

SQL / Firebase (for storing user & transaction data)

🧠 System Workflow

User inserts plastic bottle

Sensor detects object presence

Weight verification using Load Cell

(Optional) Image validation using OpenCV

Bottle accepted/rejected

Reward points generated

Data stored in database

📊 Functional Modules

Bottle Detection Module

Weight Verification Module

Reward Management Module

Database Logging Module

User Interface Display
